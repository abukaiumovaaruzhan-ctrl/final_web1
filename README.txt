SPINPOINT — FINAL PROJECT (FRONT-END DEMO)

Files:
- index.html       Home page
- club.html        Training sessions, search, filter, favourites, calculator, FAQ
- join.html        Booking form with validation and localStorage booking history
- account.html     Sign up, log in, profile, favourites and booking history
- css/style.css    Shared responsive styles and light/dark theme variables
- js/app.js        Shared JavaScript functionality

How to run locally:
1. Open Terminal in this folder.
2. Run: python3 -m http.server 8000
3. Open: http://localhost:8000

Features:
- Responsive layout and Bootstrap 5.3.3
- Light/dark mode saved in localStorage
- Demo sign up / log in / log out
- Favourite training sessions saved as JSON
- Booking requests saved as JSON
- Search, level filter, empty state and price calculator
- Form validation with inline error messages
- jQuery FAQ, reveal and hover effects

IMPORTANT:
This is a front-end demonstration. There is no backend and no real authentication or payment.
Passwords are stored in browser localStorage for demonstration only. Never use a real or reused password.
